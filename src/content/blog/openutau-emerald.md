Quando a comunidade fala em **OpenUtau Emerald**, a referência pública encontrada é o **UtauV**, um fork associado ao projeto Emerald. O projeto Emerald também mantém uma coleção de vozes para UTAU e DiffSinger, então é importante separar o editor do conjunto de voicebanks que ele ajuda a distribuir.

## O que caracteriza o UtauV

O UtauV segue a ideia de um editor baseado no OpenUtau, mas oferece builds próprias e um fluxo de distribuição ligado ao projeto Emerald. As releases públicas listam versões para Windows, macOS e Linux. Em alguns pacotes para Windows e Linux aparecem opções DirectML e CUDA, destinadas a cenários diferentes de aceleração.

Isso torna o fork relevante para usuários que trabalham com as vozes do ecossistema Emerald e querem acompanhar uma distribuição preparada para esse conjunto de ferramentas. O desempenho, a compatibilidade e os requisitos variam conforme o sistema e o pacote escolhido.

## Como avaliar antes de usar

Confira a release correspondente ao seu sistema, leia as instruções de instalação e mantenha uma cópia dos projetos antes de testar um fork. Também vale confirmar a licença de cada voicebank, porque o editor e as vozes são recursos separados.
