Quando alguém procura uma ferramenta de vocal synth, normalmente está procurando uma solução para uma tarefa concreta: editar notas, instalar uma voz, melhorar a pronúncia, treinar um modelo ou apenas ouvir uma ideia. Não existe uma ferramenta única que faça tudo bem.

## Para editar e cantar

O [OpenUtau](https://github.com/openutau/OpenUtau) é uma porta de entrada forte para edição vocal. Ele oferece editor de notas, múltiplas trilhas, phonemizers, resamplers e suporte a diferentes sistemas de voz. A [wiki oficial](https://github.com/openutau/OpenUtau/wiki) reúne guias para instalação, primeiros passos e desenvolvimento de voicebanks.

O UTAU original continua importante para entender a história e muitos bancos existentes, mas seu fluxo pode exigir cuidados específicos com locale, plugins e arquivos antigos. Usar OpenUtau não apaga essa história, apenas oferece uma maneira mais atual de acessá-la.

## Para síntese neural

O [DiffSinger](https://github.com/MoonInTheRiver/DiffSinger) é o caminho para estudar uma cadeia baseada em modelos neurais, dados musicais e vocoders. Ele é mais exigente para quem quer treinar uma voz, mas permite compreender uma camada diferente da síntese vocal.

Forks como [OpenUtau Lunai](https://github.com/keirokeer/OpenUtau-lunai) e [UtauV](https://github.com/emeraldsingers/UtauV) mostram como a comunidade adapta o editor para cantores e fluxos específicos.

## Uma forma simples de escolher

Pergunte primeiro:

- Quero editar ou treinar?
- A voz já existe ou preciso criar um banco?
- Meu projeto precisa rodar em Windows, macOS ou Linux?
- A licença permite o uso que imagino?
- Tenho tempo e hardware para configurar dependências?

Se você está começando, escolha uma ferramenta com documentação e uma comunidade acessível. Uma instalação que funciona e permite aprender é mais valiosa do que uma lista enorme de recursos que você ainda não consegue testar.

## Software livre é processo

Abertura não significa que tudo seja simples, gratuito em todos os sentidos ou livre de manutenção. Significa que o projeto pode ser estudado, adaptado e compartilhado dentro da licença. Documentação, issues, traduções e relatos de usuários também fazem parte da infraestrutura.
